# Projet_Cin-

Projet de fin d'année du module "pWEBD1 - JavaScript Web Development"

Le sujet de ce projet est la création d'un site internet axé sur le cinéma et les sorties de films.

Pour créer ce site, nous avons utilisé l'API de Omdb, une bibliothèque gratuite et participative qui référence des millions de films, avec toutes les informations qui leur sont liés :
    - titre
    - date de sortie
    - réalisateur
    - acteurs
    - synopsis
    etc...

Le site comprend 4 pages :

- index/accueil :
On retrouve sur cette page les 3 films tendances de cette année ainsi qu'une liste de films parus en 2026 (seuls les films contenant le mot "man" apparaissent, pour limiter le nombre de requêtes envoyées à l'API).

- movie :
Elle contient toutes les informations utiles du film sélectionné. On y accède grâce aux boutons "En savoir plus".

- search :
Page dédiée à la recherche de films de façon dynamique, les résultats arrivant en temps réel. L'utilisateur peut ici rechercher des films et obtenir les informations liées.

- contact :
Un formulaire de contact pour demander des renseignements.
